# NexoBrowser workspace

This repository is a Cursor cloud workspace. The product is **NexoBrowser**, a
Windows x86_64 portable build based on upstream
[Camoufox](https://github.com/daijro/camoufox) with Settings/Preferences chrome
entry points removed.

See [`nexo-browser/CHANGES.md`](nexo-browser/CHANGES.md) for branding and UI
source changes, and [`nexo-browser/build-windows-x86_64.sh`](nexo-browser/build-windows-x86_64.sh)
to compile from source (do not use a prebuilt Camoufox GitHub Release).
